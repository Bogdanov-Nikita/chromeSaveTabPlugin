# Tab Saver
[English](ReadMe.md)

**Tab Saver** — это легковесное, безопасное и функциональное браузерное расширение (WebExtension), предназначенное для сохранения, структурирования и быстрого восстановления открытых вкладок браузера.

Проект поддерживает экспорт вкладок в форматы `TXT`, `HTML` и `JSON`, включает умное восстановление сессий, отображение оригинальных иконок сайтов, защиту от XSS-атак, гибкую опцию группировки ссылок по доменам и полную мультиязычность.

## 🚀 Основные возможности

- **Умный экспорт в 3 формата:**
  - **TXT (Текстовый список):** Простой список всех открытых URL, оформленный в виде структуры или плоского перечня.
  - **HTML (Интерактивный отчет):** Автономная, визуально приятная страница с иконками сайтов (`favicons`) и интерактивным сворачиванием списков на базе тегов `<details>` и `<summary>`.
  - **JSON (Резервная копия):** Структурированный файл бэкапа, сохраняющий метаданные (заголовки, URL, иконки) для последующего точного восстановления.
- **Опция «Группировать по доменам»:** Специальный чекбокс в интерфейсе позволяет выбирать, как сохранять данные — с автоматическим разделением вкладок по именам сайтов (доменам) или единым плоским списком в исходном порядке.
- **Безопасность и защита от XSS:** Все генерируемые данные (заголовки, URL-адреса, имена доменов) проходят тотальное HTML-экранирование, что полностью исключает возможность выполнения вредоносного кода при открытии сохраненных файлов.
- **Умное восстановление сессий (Импорт JSON):** Алгоритм импорта автоматически распределяет вкладки по новым окнам в фоновом режиме (не сбивая фокус пользователя):
  - Крупные группы доменов (более 10 вкладок) открываются в отдельных персональных окнах.
  - Остальные вкладки группируются и открываются пачками строго по 20 штук в окне, защищая браузер от зависаний.
- **Кроссбраузерность:** Google Chrome (Chromium) и Mozilla Firefox.
- **Интернационализация (i18n):** Интерфейс боковой панели и генерируемые файлы полностью локализованы (поддерживаются русский и английский языки).

## 🛠️ Установка и запуск

### Для Chromium-браузеров (Google Chrome, Яндекс.Браузер, Edge, Opera):

1. Перейдите по адресу `chrome://extensions/`.
2. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
4. Выберите корневую папку проекта `Tab-Saver`.
5. Нажмите на иконку расширения на панели инструментов, чтобы открыть боковую панель.

## 📝 Ключевые функции в `side.js`

### `processingSaveTabs(type)`
Управляет асинхронным процессом сбора вкладок через `browser.tabs.query`, считывает состояние чекбокса группировки, блокирует элементы UI на время выполнения и инициирует скачивание итогового файла.

### `restoreTabsFromJSON(jsonString)`
Парсит резервную копию JSON и применяет алгоритм безопасного распределения ссылок по окнам браузера. Перед запуском проверяет валидность структуры файла и выводит понятные уведомления в случае ошибок.
